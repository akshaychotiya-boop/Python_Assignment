# Python_Assignment
Sample Python Assignments for practicing if you are new to Python
# Assignments:
1. Grade Checker
Take a score as input and print the grade based on the following:<br>
90+ : "A"<br>
80-89 : "B"<br>
70-79 : "C"<br>
60-69 : "D"<br>
Below 60 : "F"<br>
here we used a basic if else statement to carry out marks and all.

2. Student Grades
Create a dictionary where the keys are student names and the values are their grades. Allow the user to:<br>
Add a new student and grade.<br>
Update an existing student’s grade.<br>
Print all student grades.

3. Write to a File
Write a program to create a text file and write some content to it.

4. Read from a File
We used open in read mode and file.read to read and print to display.
